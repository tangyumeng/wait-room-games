# wait-room-games

Public GitHub Pages site for **Wait Room Games**.

Same pattern as Mac App Store sites (`sizedrop-pages`, `animlens-pages`): this repository is support and privacy pages only. The iOS source is not published.

## Live URLs

- Home: https://tangyumeng.github.io/wait-room-games/
- Privacy: https://tangyumeng.github.io/wait-room-games/privacy/
- app-ads.txt (this site): https://tangyumeng.github.io/wait-room-games/app-ads.txt

AdMob’s crawler is supposed to fetch the **domain root**:
https://tangyumeng.github.io/app-ads.txt
That file lives in `tangyumeng/tangyumeng.github.io`. A copy is also in this repo so the store marketing URL path does not 404.

## Deploy

Push `main`. GitHub Pages is set to deploy from the `main` branch root.
